
AnjonesExam — Smart Online Examination System

A Django-based online examination platform designed to support digital assessments, question management, student participation, examination scheduling, and automated result processing.

Project Overview

AnjonesExam is an online examination system designed to help educational institutions conduct and manage examinations through a web-based platform.

The system provides a digital environment for organizing examinations, managing questions, controlling examination access, recording student responses, and processing results.

The project demonstrates my skills in Python, Django, database design, authentication, role-based access control, examination workflow development, and responsive web application development.

Main Features

- User Authentication: Provide login and access management for authorized users.
- Role-Based Access Control: Support different permissions for administrators, teachers, and students.
- Examination Management: Create, configure, and manage online examinations.
- Question Management: Organize examination questions and their associated answers.
- Multiple-Choice Questions: Support objective questions where implemented.
- Examination Scheduling: Configure examination dates, times, and availability.
- Student Examination Interface: Provide an interface for students to access and complete examinations.
- Timed Examinations: Support time-limited examinations.
- Full-Screen Examination Interface: Provide a focused examination environment.
- Question Navigation: Allow students to move between examination questions.
- Question Flagging: Enable students to mark questions for later review.
- Response Recording: Record student answers during examinations.
- Automated Evaluation: Calculate scores for supported automatically graded question types.
- Result Management: Store and display examination results to authorized users.
- Teacher Dashboard: Support examination and question management.
- Student Dashboard: Provide access to available examinations and relevant results.
- Administrative Dashboard: Manage users and oversee examination activities.
- Responsive Interface: Support access through desktop and mobile browsers.
